# Kit (ConvertKit) GraphQL API

Kit (formerly ConvertKit) is a creator email marketing platform. This conceptual GraphQL schema wraps the Kit REST API v4, providing queries for subscribers, tags, sequences, forms, broadcasts, and automation rules with support for bulk operations and cursor-based pagination.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Kit API v4
**Documentation:** https://developers.kit.com/

- Reference: https://developers.kit.com/reference
- Schema: https://github.com/api-evangelist/convertkit
